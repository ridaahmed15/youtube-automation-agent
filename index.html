🎬 YouTube Automation Agent

An AI-powered pipeline that plans, writes, produces and publishes YouTube content automatically, from strategy to analytics.

View Source on GitHub

Pipeline Agents

📈 Strategy

Plans content topics and the channel growth direction.

📝 Script

Generates video scripts with AI text providers.

🖼️ Thumbnail

Creates eye-catching thumbnails for each video.

🔎 SEO

Optimises titles, descriptions and tags for search.

🎞️ Production

Renders the final video using FFmpeg and media providers.

🚀 Publishing

Uploads and schedules videos to YouTube.

📊 Analytics

Tracks performance and feeds results back into strategy.

Tech Stack

Node.js Express SQLite FFmpeg Cron Scheduling YouTube OAuth Multi-AI Providers
